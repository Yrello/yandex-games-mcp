# Установка на Windows

Это руководство предназначено для новой установки из GitHub. Каждый пользователь
настраивает MCP и авторизует собственный отдельный профиль браузера. Не копируйте
чужие cookies или каталог профиля.

## 1. Получите исходники

Можно клонировать репозиторий через Git:

```powershell
git clone https://github.com/Yrello/yandex-games-mcp.git "$HOME\Yandex Games MCP"
Set-Location "$HOME\Yandex Games MCP"
```

Или скачайте ZIP репозитория на GitHub, распакуйте его в удобную папку и откройте
PowerShell в этой папке.

## 2. Установите зависимости

Установите Node.js версии 18 или новее и Google Chrome. Проверьте, что `node` и `npm` доступны
в PowerShell:

```powershell
node --version
npm --version
npm ci
```

Если в GitHub-архиве нет `package-lock.json`, используйте `npm install` вместо
`npm ci`.

## 3. Выполните вход в Яндекс

Перед регистрацией сервера в Codex запустите отдельную авторизацию с видимым
окном браузера:

```powershell
npm run login
```

Войдите в нужный аккаунт Яндекса в открывшемся окне и завершите команду после
подтверждения входа. По умолчанию данные MCP хранятся в
`%USERPROFILE%\.codex\mcp\yandex-games`: профиль браузера — в `profile`, а файлы
вывода — в соседней папке `output`. Этот путь отдельный для каждого пользователя
Windows и сохраняет существующий профиль при обновлении установки. Не переносите
профиль на другой компьютер, не добавляйте его в Git и не передавайте архивом.
При необходимости задайте `YG_MCP_DATA_DIR`, чтобы выбрать другой каталог данных.
При потере доступа повторите вход на этом компьютере.

Во время первого входа и последующей работы с MCP не запускайте другой MCP-браузер
с тем же профилем. Одним профилем одновременно должен владеть только один процесс.

## 4. Зарегистрируйте MCP в Codex

Сначала закройте активное подключение `yandex_games`, если оно уже запущено.
Затем откройте пользовательский файл `%USERPROFILE%\.codex\config.toml` и добавьте
запись ниже. Замените путь в `args` на полный путь к `src/server.mjs` в вашей
папке клона. Прямые слеши в TOML подходят для Windows путей:

```toml
[mcp_servers.yandex_games]
command = "node"
args = ["C:/Users/ВАШЕ_ИМЯ/Yandex Games MCP/src/server.mjs"]
# Необязательно: другой каталог для профиля и output.
# env = { YG_MCP_DATA_DIR = "D:/CodexData/yandex-games" }
```

Сохраните файл и перезапустите Codex или MCP-подключение. Для проверки вызовите
`list_games` в Codex. Не запускайте параллельно второй экземпляр этого сервера,
пока он использует тот же профиль.

## Дополнительный Playwright MCP

Специализированный сервер предоставляет ограниченный набор команд для консоли
Яндекс Игр. Если вам нужны инструменты официального Playwright MCP, которых здесь
нет, установите и зарегистрируйте официальный сервер отдельно по его актуальной
документации. Настройте для него собственный профиль браузера. Не подключайте его
к профилю этого wrapper и не запускайте одновременно два браузера с одним
профилем.

## Обновление и удаление

Чтобы обновить клонированный репозиторий, остановите подключение MCP, получите
новую версию исходников и выполните `npm ci`. После этого перезапустите Codex.
Профиль авторизации находится вне папки репозитория. При удалении приложения
удалите его отдельно, только если больше не нужна сохранённая сессия.
