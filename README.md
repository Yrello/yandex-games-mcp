# Yandex Games MCP

Локальный MCP-сервер для консоли разработчика Яндекс Игр. Он позволяет работать с играми и черновиками через инструменты MCP-клиента: читать данные, редактировать поля и загружать файлы.

Сервер использует Google Chrome и официальный Playwright MCP. Авторизация выполняется в браузере; вручную копировать cookies или токены не нужно.

## Возможности

- Просмотр игр, черновиков, доступных локализаций, ошибок заполнения и истории модерации.
- Изменение текстовых полей, категорий, тегов и возрастного рейтинга черновика.
- Добавление локализаций карточки игры и управление лидербордами.
- Загрузка сборки, иконки, обложки и скриншота с проверкой результата после сохранения.
- Локальная проверка размеров и формата изображений до загрузки.

Сервер не отправляет игры на модерацию и не публикует их.

## Требования

- Node.js 18 или новее и npm.
- Google Chrome.
- MCP-клиент с поддержкой локальных серверов через stdio. Ниже приведена настройка для Codex на Windows.

## Установка

```powershell
git clone https://github.com/Yrello/yandex-games-mcp.git
Set-Location yandex-games-mcp
npm ci
npm run login
```

Команда `npm run login` открывает Chrome. Войдите в свой аккаунт Яндекса и подтвердите вход в терминале. Запускайте её в интерактивном терминале.

Добавьте сервер в `%USERPROFILE%\.codex\config.toml`. Замените путь на абсолютный путь к `src/server.mjs` в вашем клоне:

```toml
[mcp_servers.yandex_games]
command = "node"
args = ["C:/Users/ВАШЕ_ИМЯ/yandex-games-mcp/src/server.mjs"]
```

Перезапустите Codex и вызовите `list_games` для проверки подключения. Отдельно устанавливать Playwright MCP не требуется: он указан в зависимостях проекта. Подробная инструкция есть в [INSTALL.md](INSTALL.md).

## Инструменты

| Инструмент | Назначение |
| --- | --- |
| `inspect_console` | Проверить доступ к консоли. |
| `list_games` | Получить список игр аккаунта и их статусы. |
| `get_draft` | Прочитать черновик и состояние сборки. |
| `inspect_draft_form` | Посмотреть доступные элементы формы черновика. |
| `get_draft_localizations` | Посмотреть языки черновика и доступные элементы выбора локализации. |
| `add_draft_localization` | Добавить локализацию карточки в черновик и проверить сохранение. |
| `check_draft` | Получить известные ошибки и незаполненные поля. |
| `get_moderation_feedback` | Прочитать ошибки проверки и историю модерации. |
| `check_media_files` | Локально проверить PNG-иконку или обложку. |
| `update_fields` | Изменить текстовые поля русской версии черновика. |
| `update_localized_fields` | Изменить текстовые поля выбранной локализации черновика. |
| `upload_draft_media` | Загрузить иконку или обложку. |
| `upload_draft_screenshot` | Добавить горизонтальный скриншот для компьютера. |
| `update_draft_classification` | Добавить категории и теги. |
| `update_draft_age_rating` | Установить возрастной рейтинг. |
| `inspect_leaderboard_form` | Посмотреть элементы вкладки лидербордов без изменения настроек. |
| `list_leaderboards` | Получить список лидербордов игры. |
| `get_leaderboard` | Прочитать настройки лидерборда по техническому имени. |
| `create_leaderboard` | Создать лидерборд с локализованными названиями и проверить сохранение. |
| `update_leaderboard` | Изменить техническое имя, названия или признак основного лидерборда. |
| `delete_leaderboard` | Удалить выбранный лидерборд после подтверждения в Консоли. |
| `upload_build` | Загрузить ZIP-сборку. |

Команды записи сохраняют изменения и затем проверяют результат повторным чтением. Локализации карточки игры и поле «Игра переведена на» учитываются отдельно. Удалённое техническое имя лидерборда нельзя использовать повторно. Для загрузки файлов используйте пути внутри каталога проекта. ZIP-сборка должна быть не больше 100 МиБ и содержать `index.html` в корне. Для `check_media_files` нужны PNG-иконка 512 × 512 и обложка 800 × 470.

## Безопасность

Профиль Chrome с данными входа по умолчанию хранится вне репозитория, в `%USERPROFILE%\.codex\mcp\yandex-games`. Путь можно изменить через `YG_MCP_DATA_DIR`. Не добавляйте профиль в Git и не передавайте его другим людям.

Не запускайте два экземпляра сервера с одним профилем одновременно. Перед повторным входом через `npm run login` остановите подключённый MCP-сервер. Если результат записи неизвестен, сначала проверьте черновик через `get_draft`, прежде чем повторять действие.

## Разработка

```powershell
npm test
```

Код сервера находится в `src/`. Диагностический клиент `yandex-mcp-check.mjs` запускайте только после остановки основного подключения.
